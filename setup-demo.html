DishDash cloud setup

One-time connection between this browser and your Supabase project. Every step is safe to re-run.

1 Connect to Supabase

Reading assets/js/supabase-config.js…

window.DD_SUPABASE_CONFIG = {
  SUPABASE_URL: 'https://YOUR-PROJECT.supabase.co',
  SUPABASE_ANON_KEY: 'eyJ…your anon public key'
};

2 Create the demo accounts

Registers the six DishDash demo users (admin + 5 customers) with Supabase Auth. Passwords: admin123 for the admin, demo1234 for customers. Accounts that already exist are simply skipped.

3 Make admin@dishdash.ng the administrator

Promotes the admin profile. This works right now because the schema allows the first admin to self-promote once; afterwards only admins can manage roles.

4 Seed the demo orders & favourites

Copies the nine demo orders (DD-1001 → DD-1009) and a few favourites into Supabase so every browser sees the same rich history. Skips orders that already exist.

5 Done — open the site

Any browser pointed at this site now shares one live dataset: order in Chrome as a customer, watch it appear in Firefox's admin console. The demo orders' status will also advance automatically over time like before.
